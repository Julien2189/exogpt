1Introduction à Java

Java est un langage de programmation orienté objet, créé par James Gosling chez Sun Microsystems en 1995. Aujourd'hui maintenu par Oracle, Java est l'un des langages les plus utilisés au monde.

Pourquoi apprendre Java ?

  • Portabilité — «Write Once, Run Anywhere» : le bytecode Java tourne sur n'importe quelle machine disposant d'une JVM.
  • Robustesse — Typage fort, gestion mémoire automatique (Garbage Collector).
  • Écosystème immense — Spring Boot, Android, Big Data (Hadoop), microservices…
  • Communauté massive — Des millions de développeurs, des tonnes de bibliothèques.
  • Employabilité — Java reste le n°1 en entreprise dans le monde.

Comment ça fonctionne ?

Java utilise un processus en deux étapes :

  1. Le compilateur (javac) transforme le code source .java en bytecode .class.
  2. La JVM (Java Virtual Machine) exécute ce bytecode sur n'importe quel système.
Java est un langage compilé ET interprété. Le bytecode est interprété (ou compilé JIT) par la JVM.

Votre premier programme

Créez un fichier HelloWorld.java :

    public static void main(String[] args) {

    }

Compiler et exécuter

javac HelloWorld.java    // Compilation → HelloWorld.class
java HelloWorld          // Exécution → Bonjour, Java !
Règle d'or : le nom du fichier doit correspondre exactement au nom de la classe publique (casse comprise).

Structure d'un programme Java

  • public class NomClasse — Déclaration de la classe.
  • public static void main(String[] args) — Le point d'entrée du programme.
  • System.out.println() — Afficher du texte dans la console.

13Héritage

L'héritage permet à une classe enfant de récupérer les attributs et méthodes d'une classe parent.

// Classe parent
public class Animal {
    protected String nom;
    protected int age;

    public Animal(String nom, int age) {
        this.nom = nom;
        this.age = age;
    }

    public void manger() {
        System.out.println(nom + " mange.");
    }

    public void parler() {
        System.out.println(nom + " fait un bruit.");
    }
}

// Classe enfant
public class Chien extends Animal {
    private String race;

    public Chien(String nom, int age, String race) {
        super(nom, age);  // Appel du constructeur parent
        this.race = race;
    }

    @Override
    public void parler() {
        System.out.println(nom + " aboie ! Wouf !");
    }

    public void chercher() {
        System.out.println(nom + " rapporte la balle !");
    }
}

// Utilisation :
Chien rex = new Chien("Rex", 3, "Berger Allemand");
rex.manger();     // Rex mange.         (hérité)
rex.parler();     // Rex aboie ! Wouf !  (redéfini)
rex.chercher();   // Rex rapporte la balle ! (propre)
Java ne supporte pas l'héritage multiple de classes. Une classe ne peut étendre qu'une seule classe parent. Utilisez les interfaces pour contourner cette limitation.

14Polymorphisme

Le polymorphisme permet d'utiliser une même référence de type parent pour pointer vers des objets enfants différents.

public class Chat extends Animal {
    public Chat(String nom, int age) {
        super(nom, age);
    }

    @Override
    public void parler() {
        System.out.println(nom + " miaule ! Miaou !");
    }
}

// Polymorphisme en action
Animal[] animaux = {
    new Chien("Rex", 3, "Labrador"),
    new Chat("Minou", 2),
    new Chien("Buddy", 5, "Golden")
};

for (Animal a : animaux) {
    a.parler();  // Appelle la bonne version selon le type réel
}
// Rex aboie ! Wouf !
// Minou miaule ! Miaou !
// Buddy aboie ! Wouf !

// instanceof pour vérifier le type
if (animaux[0] instanceof Chien chien) {
    chien.chercher();  // Pattern matching (Java 16+)
}

15Abstraction & Interfaces

Classes abstraites

public abstract class Forme {
    protected String couleur;

    public Forme(String couleur) {
        this.couleur = couleur;
    }

    // Méthode abstraite : pas de corps, doit être implémentée
    public abstract double aire();
    public abstract double perimetre();

    // Méthode concrète : les enfants en héritent
    public void afficher() {
        System.out.println("Forme " + couleur + ", aire = " + aire());
    }
}

public class Cercle extends Forme {
    private double rayon;

    public Cercle(String couleur, double rayon) {
        super(couleur);
        this.rayon = rayon;
    }

    @Override
    public double aire() { return Math.PI * rayon * rayon; }

    @Override
    public double perimetre() { return 2 * Math.PI * rayon; }
}

Interfaces

public interface Volant {
    void decoller();
    void atterrir();

    // Méthode par défaut (Java 8+)
    default void planer() {
        System.out.println("Je plane...");
    }

    // Méthode statique
    static int altitudeMax() {
        return 10000;
    }
}

public interface Nageant {
    void nager();
}

// Une classe peut implémenter plusieurs interfaces
public class Canard extends Animal implements Volant, Nageant {
    public Canard(String nom) { super(nom, 1); }

    @Override public void parler() { System.out.println("Coin coin !"); }
    @Override public void decoller() { System.out.println("Le canard décolle !"); }
    @Override public void atterrir() { System.out.println("Le canard atterrit."); }
    @Override public void nager() { System.out.println("Le canard nage."); }
}
Règle : Utilisez une classe abstraite quand les enfants partagent du code. Utilisez une interface quand vous voulez définir un contrat sans imposer d'héritage.

24JDBC — Bases de données

JDBC (Java Database Connectivity) permet de se connecter à des bases de données SQL.

import java.sql.*;

public class DatabaseDemo {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost:3306/mabase";
        String user = "root";
        String pass = "motdepasse";

        try (Connection conn = DriverManager.getConnection(url, user, pass)) {

            // CREATE
            String sql = "INSERT INTO utilisateurs (nom, email) VALUES (?, ?)";
            try (PreparedStatement pstmt = conn.prepareStatement(sql)) {
                pstmt.setString(1, "Alice");
                pstmt.setString(2, "alice@mail.com");
                pstmt.executeUpdate();
            }

            // READ
            String query = "SELECT * FROM utilisateurs WHERE nom LIKE ?";
            try (PreparedStatement pstmt = conn.prepareStatement(query)) {
                pstmt.setString(1, "%Ali%");
                ResultSet rs = pstmt.executeQuery();
                while (rs.next()) {
                    System.out.println(rs.getInt("id") + " - " +
                                       rs.getString("nom") + " - " +
                                       rs.getString("email"));
                }
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}

import com.sun.net.httpserver.HttpServer;

import java.net.InetSocketAddress;

public class MiniServeurHttp {
    public static void main(String[] args) throws Exception {

        HttpServer server = HttpServer.create(
                new InetSocketAddress(8080),
                0
        );

        server.createContext("/", exchange -> {
            String html = """
<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title>Serveur Java</title>
</head>
<body>
    <h1>Bonjour depuis Java !</h1>
    <p>Ce site est généré par un serveur Java.</p>
</body>
</html>
""";

            exchange.getResponseHeaders().set("Content-Type", "text/html; charset=UTF-8");
            exchange.sendResponseHeaders(200, html.getBytes().length);

            try (OutputStream os = exchange.getResponseBody()) {
                os.write(html.getBytes());
            }
        });

        server.start();

    }
}

41Serveur multi-clients avec Threads

Un serveur simple ne gère qu’un client à la fois. Pour gérer plusieurs clients, on peut créer un thread par client.

Serveur multi-clients

import java.io.*;
import java.net.*;

public class ServeurMultiClients {

    public static void main(String[] args) throws IOException {
        ServerSocket serveur = new ServerSocket(5000);
        System.out.println("Serveur multi-clients lancé.");

        while (true) {
            Socket client = serveur.accept();
            System.out.println("Nouveau client connecté.");

            new Thread(() -> gererClient(client)).start();
        }
    }

    private static void gererClient(Socket client) {
        try (
            BufferedReader in = new BufferedReader(
                    new InputStreamReader(client.getInputStream())
            );
            PrintWriter out = new PrintWriter(
                    client.getOutputStream(),
                    true
            )
        ) {
            String message;

            while ((message = in.readLine()) != null) {
                System.out.println("Client : " + message);
                out.println("Serveur a reçu : " + message);

                if (message.equalsIgnoreCase("quit")) {
                    break;
                }
            }

        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
Un thread par client est simple pour apprendre. Pour un vrai serveur à grande échelle, on utilise des pools de threads, NIO, Netty ou Spring Boot.

44Projet réseau complet — Mini client API avec interface Swing

Ce projet combine Swing et réseau. L’utilisateur clique sur un bouton, Java appelle une API HTTP, puis affiche la réponse dans l’interface.

Code complet

import java.awt.*;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.time.Duration;

public class ApiSwingApp extends JFrame {

    private final JTextArea zoneResultat;
    private final JButton boutonCharger;

    public ApiSwingApp() {
        super("Client API Java Swing");

        zoneResultat = new JTextArea();
        zoneResultat.setLineWrap(true);
        zoneResultat.setWrapStyleWord(true);
        zoneResultat.setEditable(false);

        boutonCharger = new JButton("Charger les données");

        JPanel panelHaut = new JPanel();
        panelHaut.add(boutonCharger);

        add(panelHaut, BorderLayout.NORTH);
        add(new JScrollPane(zoneResultat), BorderLayout.CENTER);

        boutonCharger.addActionListener(e -> chargerApi());

        setSize(700, 500);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLocationRelativeTo(null);
    }

    private void chargerApi() {
        boutonCharger.setEnabled(false);
        zoneResultat.setText("Chargement en cours...");

        new SwingWorker<String, Void>() {

            @Override
            protected String doInBackground() throws Exception {
                return appelerApi();
            }

            @Override
            protected void done() {
                try {
                    zoneResultat.setText(get());
                } catch (Exception e) {
                    zoneResultat.setText("Erreur réseau : " + e.getMessage());
                } finally {
                    boutonCharger.setEnabled(true);
                }
            }
        }.execute();
    }

    private String appelerApi() throws Exception {
        HttpClient client = HttpClient.newBuilder()
                .connectTimeout(Duration.ofSeconds(5))
                .build();

        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create("https://api.github.com"))
                .timeout(Duration.ofSeconds(10))
                .GET()
                .build();

        HttpResponse<String> response = client.send(
                request,
                HttpResponse.BodyHandlers.ofString()
        );

        return "Code HTTP : " + response.statusCode() + "\n\n" + response.body();
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            new ApiSwingApp().setVisible(true);
        });
    }
}

Hasher un mot de passe avec BCrypt

import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;

public class PasswordService {

    private BCryptPasswordEncoder encoder = new BCryptPasswordEncoder();

    public String hasherMotDePasse(String motDePasse) {
        return encoder.encode(motDePasse);
    }

    public boolean verifierMotDePasse(String brut, String hash) {
        return encoder.matches(brut, hash);
    }
}

59 Déploiement d’une application Java

Une fois ton application terminée, il faut savoir la compiler, la livrer et la lancer sur une autre machine.

Créer un fichier JAR avec Maven

mvn clean package

Maven génère généralement le fichier dans le dossier target/. 

target/mon-application.jar

Lancer un fichier JAR

java -jar mon-application.jar

Variables d’environnement

On évite d’écrire les mots de passe directement dans le code. On utilise plutôt des variables d’environnement. 

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=secret

Dockerfile simple

FROM eclipse-temurin:17-jdk

WORKDIR /app

COPY target/mon-application.jar app.jar

EXPOSE 8080

CMD ["java", "-jar", "app.jar"]

Construire et lancer avec Docker

docker build -t mon-app-java .
docker run -p 8080:8080 mon-app-java
À retenir : savoir déployer ton application te fait passer du niveau “je code” au niveau “je livre un vrai projet”.
